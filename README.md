# FunPay Dark Theme

Небольшое расширение Manifest V3, которое заменяет светлую тему FunPay на тёмную AMOLED-тему.

## Установка в Chrome / Edge / Brave / Яндекс Браузер

1. Скачайте и распакуйте архив `funpay-dark-extension.zip`.
2. Откройте страницу расширений: `chrome://extensions` (в Яндекс Браузере — `browser://extensions`).
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите папку `funpay-dark-extension`.
5. Откройте или обновите страницу [funpay.com](https://funpay.com).

## Установка в Firefox

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **Загрузить временное дополнение**.
3. Выберите файл `manifest.json` из распакованной папки.

Тема включена по умолчанию. Нажмите на значок расширения, чтобы временно выключить её — настройка сохраняется автоматически.

## Что затемняется

- навигация, панели, таблицы и карточки лотов;
- поиск, поля ввода, выпадающие меню и модальные окна;
- чат, отзывы, фильтры и кнопки;
- фон страницы, скроллбары и подсветка при наведении.

Изображения товаров и баннеры не инвертируются, поэтому их цвета остаются естественными.
